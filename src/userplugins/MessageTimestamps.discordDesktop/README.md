# MessageTimestamps

Adapted from [fagnersales/vencord-plugins](https://github.com/fagnersales/vencord-plugins/tree/main/messageTimestamps), by fagner, GPL-3.0-or-later.

The Mc5mr port uses Equicord's declarative MessageDecorations API, a single paired minute timer, localized relative times and an exact-time tooltip. It preserves Discord's grouped timestamp styling and does not query the DOM. The feature can be disabled in plugin settings.
