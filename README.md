# EquicordPrivatee recovery

This repository restores the Equicord source and the custom plugin folders recovered from the local build workspace on 2026-11-09.

## Custom plugins

- `src/userplugins` contains the recovered user plugin source folders.
- `src/esharqplugins` contains the recovered Equicord-specific plugin source folders.
- The source also includes the base Equicord plugins required by the custom build.

The local recovery contained 50 user plugin folders and 83 Equicord-specific folders in its earlier full backup. Later local work added further folders, so every recovered folder has been retained rather than discarding newer work to force a count.

`THIRD_PARTY_PLUGINS.md` records the upstream attribution for third-party additions. Original author and license notices are retained.
